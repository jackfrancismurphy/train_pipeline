### Train Delay Leaderboard

A real-time leaderboard which shames the privatised train companies with the most delays daily. Updated in real-time as the companies race to the bottom in their reliability!

This application require a secrets.json file at the top level containing these fields at least:

    "bootstrap_servers": "...",
    "sasl_username": "...",
    "sasl_password": "...",
    "feed_username_&_password": ["..."]
